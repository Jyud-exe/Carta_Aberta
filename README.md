# 💙 Carta para Carol

Uma pequena carta transformada em uma experiência virtual.

Este projeto foi criado especialmente para **Carol**, como uma forma diferente de transformar sentimentos em algo que pudesse ser visto, lido e guardado.

Mais do que uma página HTML, a ideia foi criar uma experiência simples e delicada, combinando **HTML, CSS e JavaScript** para transformar uma carta em uma página interativa.

## 💌 Sobre

A carta foi desenvolvida para ser visualizada diretamente pelo navegador, com elementos visuais, animações e transições pensados para tornar a leitura mais especial.

Cada detalhe da página foi feito com a intenção de representar um pouco do carinho colocado na criação dela.

## ✨ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Animações e transições CSS
* Git e GitHub

## 🛠️ Como executar localmente

Você pode abrir o projeto diretamente no navegador ou utilizar uma extensão como **Live Server** no VS Code.

1. Clone o repositório:

   ```bash
   git clone URL_DO_REPOSITORIO
   ```

2. Entre na pasta:

   ```bash
   cd carta-para-carol
   ```

3. Abra o `index.html` no navegador.

## 🌙 Objetivo

Este projeto nasceu como uma forma de unir duas coisas:

**programação + sentimento.**

Foi uma maneira de transformar uma simples carta em algo que pudesse ser acessado de qualquer lugar e que, de alguma forma, pudesse guardar aquele momento.
